# Lecture 11: Ordinary differential equations

MyST Reveal source for the 40 main slides and four optional references.
Instructor speaker notes are excluded. Figures use the executed reference
notebook and standalone SVG schematics. The spring apparatus is illustrative;
its geometry is not simulation data.

From the repository root, rebuild the self-contained slides and worked handout:

```sh
PATH="$PWD/.venv/bin:$PATH" python3 scripts/build_ode_slides.py
```

The export is copied through the existing MyST static `09-lectures/reveal`
folder. The lecture overview links both files. Notebook source links are omitted
from the export because the notebook companion page is not deployed.
